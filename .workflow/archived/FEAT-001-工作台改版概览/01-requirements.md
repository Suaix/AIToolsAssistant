# 需求文档：工作台改版为概览面板

> **任务编号**：FEAT-001
> **创建日期**：2026-04-29
> **状态**：已确认

---

## 1. 背景与目标

### 1.1 背景

当前工作台（Dashboard）页面是一个以「同步状态 HeroCard」为核心的单一状态展示页，
仅展示 Skills 的同步情况（5 态状态机：loading / cli_missing / error / empty / synced / drift）。

这偏离了产品定位——作为「AI 工具同步管家」的桌面端，工作台应该是用户打开应用后的**全局概览入口**，
让用户一目了然地掌握所有资源的整体状况，而不仅仅是 Skills 的同步状态。

### 1.2 目标

将工作台从「同步状态卡片」改版为**数据概览面板（Overview Dashboard）**，
展示 Skills、Commands、Agents、Rules、项目和已连接工具这 6 个维度的汇总数据，
让用户在首屏即可感知全局状态。

## 3. 功能范围

### 3.1 包含（In Scope）

**页面布局（上下分区）**：

```
┌─────────────────────────────────────────────┐
│  全局状态 Banner（仅 CLI 异常时显示）          │
├──────────────────────┬──────────────────────┤
│     Skills 卡片       │   Commands 卡片      │
│  已订阅/候选/待同步    │   总数（0 占位）       │
├──────────────────────┼──────────────────────┤
│     Agents 卡片       │    Rules 卡片         │
│   总数（0 占位）       │   总数（0 占位）       │
├──────────────────────┴──────────────────────┤
│               分隔区域                        │
├──────────────────────┬──────────────────────┤
│   已连接工具           │     项目              │
│   已启用数/总数        │   当前项目+最近项目数   │
└──────────────────────┴──────────────────────┘
```

- 上区：Skills / Commands / Agents / Rules — 2×2 九宫格
- 下区：已连接工具 / 项目 — 左右两列
- 上下两区之间有视觉分隔

**功能清单**：

- [ ] 上区 4 个资源卡片（2×2 网格）
- [ ] Skills 卡片：已订阅数 / 候选数 / 待同步数（实时数据）
- [ ] Commands 卡片：总数，灰色样式，显示 0（功能未实现）
- [ ] Agents 卡片：总数，灰色样式，显示 0（功能未实现）
- [ ] Rules 卡片：总数，灰色样式，显示 0（功能未实现）
- [ ] 下区 2 个数据列（左右布局）
- [ ] 已连接工具列：已启用数 / 总数（实时数据）
- [ ] 项目列：当前项目名 + 最近项目数
- [ ] 已实现的卡片点击跳转对应详情页
- [ ] 未实现的卡片点击无反应或 toast 提示「即将推出」
- [ ] CLI 异常时顶部显示全局 Banner（替代原 HeroCard 的 cli_missing / error 态）
- [ ] 完全移除原 HeroCard 组件，同步状态融入 Skills 卡片二级指标
- [ ] Sidebar 标签从「工作台」改为「概览」

### 3.2 不包含（Out of Scope）

- Commands / Agents / Rules 的详情页实现（仅在卡片上展示占位数据）
- 操作记录/活动日志（US-4 降级为 P2，本次可不实现）
- 数据图表（折线图、趋势图等可视化）

## 4. 验收标准（Acceptance Criteria）

### US-1 验收标准

- [ ] **Given** 用户打开应用 **When** 工作台加载完成 **Then** 页面展示 6 个数据卡片，分别对应 Skills / Commands / Agents / Rules / 项目 / 已连接工具
- [ ] **Given** CLI 未安装 **When** 工作台加载 **Then** 显示 CLI 未安装的提示状态，而非空的数据卡片

### US-2 验收标准

- [ ] **Given** 用户有 3 个已订阅 Skills、2 个候选、1 个待同步 **When** 查看 Skills 卡片 **Then** 卡片显示「3 已订阅 · 2 候选 · 1 待同步」
- [ ] **Given** Commands/Agents/Rules 功能未实现 **When** 查看对应卡片 **Then** 卡片显示「0」或「即将推出」，不显示错误信息

### US-3 验收标准

- [ ] **Given** Skills 功能已实现 **When** 点击 Skills 卡片 **Then** 跳转到 Skills 列表页
- [ ] **Given** Commands 功能未实现 **When** 点击 Commands 卡片 **Then** 卡片保持当前状态或显示「即将推出」提示，不发生错误

## 6. 约束与依赖

- **技术约束**：基于现有 React + Tauri 技术栈，不引入新框架
- **外部依赖**：依赖 aitools CLI 的 `list` 命令获取 Skills 和 Tools 数据
- **数据约束**：Commands / Agents / Rules 当前 CLI 不支持，卡片数据需要 mock 或显示占位
