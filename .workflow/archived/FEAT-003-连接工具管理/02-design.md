## 1. 设计目标

在现有已连接工具页面上增加「添加工具」和「移除工具」能力，保持已有的启用/禁用开关不变。三个操作正交互不干扰。

---

## 2. 信息架构

### 2.1 页面结构

```
已连接工具页（Tools）
├── 页面 Header
│   ├── 统计文字（保留）
│   ├── 「添加工具」按钮 ★
│   └── 刷新按钮（保留）
├── 工具列表
│   └── 每行：[开关] [名称+状态] [badge] [垃圾桶按钮] ★
│         ├── 开关 → enable/disable（保留不变）
│         └── 垃圾桶 → 触发移除确认弹窗
└── Toast（保留）
```

### 2.2 用户流程

```
=== 添加工具 ===
点击「添加工具」→ AddToolModal 弹窗
  ├── 选中一个工具 → CLI target add → Toast 成功 + 列表刷新
  ├── 无可选工具 → 显示空态文案
  └── 取消 → 关闭弹窗

=== 启用/禁用（保持不变）===
切换开关 → CLI target enable/disable → Toast + 刷新

=== 移除工具 ===
点击垃圾桶 → RemoveConfirmModal 弹窗
  ├── 「确认移除」→ CLI target remove → Toast 成功 + 列表刷新
  └── 「取消」→ 关闭弹窗
```

## 3. 页面设计

### 3.1 页面 Header（改动）

```
┌──────────────────────────────────────────────────────┐
│  2/3 个已启用         [+ 添加工具]    [🔄]           │
└──────────────────────────────────────────────────────┘
```

- 「添加工具」：`.btn .btn--primary .btn--sm`，Plus 图标 + 文案
- 位置：刷新按钮左侧
- 当所有预定义工具已存在时，按钮变为 disabled

### 3.2 工具行（改动：新增垃圾桶按钮）

```
┌──────────────────────────────────────────────────────┐
│  [🔘开关]   CodeBuddy              ● 启用    [🗑]    │
│             3 个订阅资源                              │
└──────────────────────────────────────────────────────┘
```

- 垃圾桶按钮：`.btn .btn--ghost .btn--icon .btn--sm`，Trash2 图标
- 默认 `opacity: 0`，行 hover 时 `opacity: 1` 渐显
- 颜色：默认 `--color-text-tertiary`，hover 时 `--color-danger-text`
- 位置：badge 右侧（行最右端）

### 3.3 AddToolModal（添加工具弹窗）

```
┌──────────────────────────────────────────┐
│  添加工具                            ✕   │
├──────────────────────────────────────────┤
│                                          │
│  选择要添加的 AI 工具：                    │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │  ✦  CodeBuddy                      │  │
│  │     ~/.codebuddy                    │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │  ✦  WorkBuddy                      │  │
│  │     ~/.workbuddy                    │  │
│  └────────────────────────────────────┘  │
│                                          │
│           [取消]                          │
└──────────────────────────────────────────┘
```

**规格**：
- `.modal`，宽度 380px
- 每个工具为可点击 Card（hover 边框高亮）
- 卡片：工具名（加粗，`text-body-sm`） + 路径（`font-mono`，`text-caption`，`--color-text-tertiary`）
- 已存在的工具不显示
- 全部已添加时：空态文案「所有支持的工具已添加」
- 点击卡片即执行添加（低风险无需二次确认）

**弹窗状态**：

| 状态 | 视觉 |
|------|------|
| 有可选 | 工具卡片列表 |
| 无可选 | 空态文案 + 取消按钮 |
| 添加中 | 选中卡片 loading spinner，其他禁用 |

### 3.4 RemoveConfirmModal（移除确认弹窗）

```
┌──────────────────────────────────────────┐
│  移除工具                            ✕   │
├──────────────────────────────────────────┤
│                                          │
│  确认移除 CodeBuddy？                     │
│                                          │
│  移除后该工具将不再接收资源同步，           │
│  已同步的文件不会被删除。                  │
│                                          │
│       [取消]        [确认移除]            │
│                                          │
└──────────────────────────────────────────┘
```

**规格**：
- `.modal`，宽度 360px
- 描述：`text-body-sm`，`--color-text-secondary`
- 「取消」：`.btn .btn--ghost`
- 「确认移除」：`.btn .btn--danger`
- 确认按钮点击后 loading 态

## 7. 设计决策记录

| 编号 | 决策 | 备选方案 | 选择原因 |
|------|------|---------|---------|
| D-1 | 添加用预定义列表点选 | 自由输入 | MVP 三个工具固定，避免错误输入 |
| D-2 | 移除用行尾垃圾桶按钮，开关保留 enable/disable | 开关关闭=移除 | 两者是正交操作，语义不同不应混合 |
| D-3 | 垃圾桶按钮 hover 显示 | 始终显示 | 保持界面克制，减少视觉噪音 |
| D-4 | 添加点选即执行 | 需二次确认 | 低风险操作，减少步骤 |
| D-5 | 移除需二次确认 | 直接移除 | 有副作用，需用户明确意图 |
