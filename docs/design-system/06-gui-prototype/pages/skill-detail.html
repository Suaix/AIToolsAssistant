Skill User

代码审查助手

提供全面的代码审查指导和最佳实践。覆盖命名、结构、测试、安全等多个维度。

使用方式

  • 在代码审查请求前，粘贴被审查代码
  • 指定审查重点（可选）：安全 / 性能 / 可读性
  • 输出包含分级问题列表与修改建议

审查维度

1. 命名与可读性
2. 函数与模块职责
3. 类型安全
4. 错误处理
5. 测试覆盖
6. 性能与复杂度
7. 安全漏洞
