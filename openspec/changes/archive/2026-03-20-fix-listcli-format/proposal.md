## Why

当前 `aitools list` 命令的输出格式存在两个问题：

1. **格式混乱**：使用 `padEnd` 对齐列宽，中文字符占位不一致导致终端表格对不齐，可读性差。
2. **缺少对比详情**：只显示一个"综合同步状态"，不展示源文件 hash 和各 AI 工具的独立状态，用户无法判断具体哪个目标需要更新。

## What Changes

- **重写 list 命令的输出格式**：从自定义 padEnd 文本对齐改为标准化的终端表格
- **新增源文件 hash 列**：展示每个 Skill 目录的 SHA-256 hash 短值（前 8 位）
- **按目标工具分列展示状态**：每个已启用的目标工具独立一列，显示该工具对应的同步状态（如"✅ 已同步"、"⚠️ 需更新"、"❌ 未同步"）
- **移除"描述"列**：精简表格，聚焦 Skill 名称和同步对比信息

目标输出格式：

```
| Skill 名称 | 源文件 hash | CodeBuddy   | Claude Code |
|------------|------------|-------------|-------------|
| pdf        | a1b2c3d4   | ✅ 已同步   | ⚠️ 需更新    |
| git-flow   | e5f6g7h8   | ❌ 未同步   | ❌ 未同步    |
```
