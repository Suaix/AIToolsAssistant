## 1. 背景与目标

### 1.1 背景

当前设置页（`Settings.tsx`）是一个 MVP 空壳，仅显示齿轮图标和占位文案「未来将支持源目录管理、同步策略、主题偏好等配置项」。用户无法在 GUI 中进行任何配置操作，需要手动编辑 YAML 文件。

### 1.2 目标

将设置页从空壳完善为功能页面，包含以下三个配置模块：
1. **源目录管理**：查看和配置 aitools 的资源源目录路径
2. **主题偏好**：切换暗色/浅色/跟随系统主题
3. **版本号展示**：显示当前 aitools CLI 和 GUI 版本信息

## 3. 功能范围

### 3.1 包含（In Scope）

- [ ] **源目录管理模块**
  - [ ] 展示当前配置的 aitools 根目录路径（默认 `~/.aitools/`）
  - [ ] 「更改」按钮，点击后打开系统文件夹选择器（Tauri open dialog）
  - [ ] 选择新目录后，弹出迁移确认弹窗，提供三个选项：
    - 「迁移资源」：将当前根目录下的子目录（skills/、commands/ 等）整体移动到新目录
    - 「创建空目录」：在新目录下创建标准子目录结构（skills/、commands/、agents/、rules/），不移动旧文件
    - 「取消」：放弃更改，关闭弹窗
  - [ ] 确认后调用 CLI 命令 `aitools config root <new_path>` 更新配置
  - [ ] 如果选择迁移，通过 CLI 命令 `aitools config root <new_path> --migrate` 执行文件移动
  - [ ] 操作完成后 Toast 提示结果（成功/失败）
  - [ ] 失败时回滚配置（根目录路径不变）
- [ ] **主题偏好模块**
  - [ ] 三选一：暗色 / 浅色 / 跟随系统
  - [ ] 选择后立即生效，持久化到 GUI 状态
- [ ] **版本信息模块**
  - [ ] 显示 aitools CLI 版本号
  - [ ] 显示桌面端 GUI 版本号
- [ ] 页面使用分区布局，每个模块有标题和描述

### 3.2 不包含（Out of Scope）

- 同步策略配置（后续需求）
- Target 管理（已在 Tools 页实现）
- 配置文件的高级编辑器
- 多语言切换

## 4. 验收标准（Acceptance Criteria）

### US-1 验收标准

- [ ] **Given** 用户进入设置页 **When** 页面加载完成 **Then** 显示当前根目录路径
- [ ] **Given** 用户点击「更改」按钮 **When** 系统弹出文件夹选择器 **Then** 可选择一个新目录
- [ ] **Given** 用户选择了新目录 **When** 选择器关闭 **Then** 弹出迁移确认弹窗，显示三个选项
- [ ] **Given** 用户点击「迁移资源」 **When** 迁移执行成功 **Then** 根目录更新为新路径，旧目录下资源已移动到新目录，Toast 提示成功
- [ ] **Given** 用户点击「创建空目录」 **When** 执行成功 **Then** 根目录更新为新路径，新目录下创建了 skills/commands/agents/rules 子目录，Toast 提示成功
- [ ] **Given** 用户点击「取消」 **When** 弹窗关闭 **Then** 根目录路径不变，无任何副作用
- [ ] **Given** 迁移/创建过程中发生错误 **When** CLI 返回失败 **Then** Toast 提示错误信息，根目录路径回滚不变

### US-2 验收标准

- [ ] **Given** 用户进入设置页 **When** 查看主题偏好 **Then** 当前激活的主题选项高亮
- [ ] **Given** 用户点击"浅色" **When** 主题切换完成 **Then** 全局立即切换为浅色模式，下次打开应用仍为浅色

### US-3 验收标准

- [ ] **Given** CLI 已安装 **When** 查看版本信息 **Then** 显示 CLI 版本号（如 v0.4.2）
- [ ] **Given** 用户查看设置页 **When** 页面加载完成 **Then** 显示 GUI 版本号

## 6. 约束与依赖

- **技术约束**：
  - CLI 需新增 `aitools config` 子命令（隐式 get/set 模式：`aitools config <key> [value]`）
  - 源目录更改命令：`aitools config root <new_path>` — 更新配置 + 创建空子目录
  - 源目录迁移命令：`aitools config root <new_path> --migrate` — 更新配置 + 移动旧目录资源到新目录
  - 文件夹选择通过 Tauri `open_directory_dialog` 实现
- **外部依赖**：CLI 版本号通过 `aitools --version` 获取
- **数据来源**：GUI 版本号从 `package.json` 或构建时注入
- **主题切换**：顶栏快捷按钮保留，设置页提供完整三选一（暗色/浅色/系统）
