## 1. 设计目标

将设置页从空壳升级为功能页面，采用分区式卡片布局。核心交互挑战在于源目录更改流程（文件夹选择 → 迁移确认弹窗 → 执行反馈），需要设计清晰的多步流程。

---

## 2. 信息架构

### 2.1 页面结构

```
设置页（Settings）
├── 源目录管理区（Card）
│   ├── 标题 + 描述
│   ├── 当前路径展示（只读）
│   └── 「更改」按钮 → 触发文件夹选择 → 弹窗
├── 主题偏好区（Card）
│   ├── 标题 + 描述
│   └── SegmentedControl（暗色 / 浅色 / 系统）
└── 关于区（Card）
    ├── CLI 版本
    └── GUI 版本
```

### 2.2 用户流程

```
进入设置页 → 查看当前配置
  │
  ├─ 源目录更改流程：
  │   点击「更改」→ 系统文件夹选择器
  │       ├── 用户取消选择 → 无操作
  │       └── 用户选中目录 → 迁移确认弹窗
  │           ├── 「迁移资源」→ CLI --migrate → loading → 成功 Toast / 失败 Toast
  │           ├── 「创建空目录」→ CLI 无 flag → loading → 成功 Toast / 失败 Toast
  │           └── 「取消」→ 关闭弹窗，无操作
  │
  ├─ 主题切换：
  │   点击选项 → 立即生效 + 持久化
  │
  └─ 版本信息：仅展示
```

### 3.3 迁移确认弹窗（Modal）

**触发**：文件夹选择器返回新路径后弹出

```
┌──────────────────────────────────────────┐
│  更改源目录                          ✕   │
├──────────────────────────────────────────┤
│                                          │
│  新目录：~/new-aitools                    │
│                                          │
│  检测到当前目录包含资源文件，              │
│  是否将资源迁移到新目录？                  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │  📦 迁移资源                        │  │
│  │  将 skills/、commands/ 等移动到新目录 │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │  📂 创建空目录                      │  │
│  │  在新目录下创建标准子目录结构         │  │
│  └────────────────────────────────────┘  │
│                                          │
│           [取消]                          │
│                                          │
└──────────────────────────────────────────┘
```

**弹窗规格**：
- 使用 L5 `.modal` 组件
- 宽度：400px
- 两个选项卡片：可点击 Card 样式，hover 边框高亮
- 选项卡片内：图标（左） + 标题 + 描述（右）
- 「取消」：居中 Ghost 按钮
- 点击选项后弹窗切换为 loading 态（spinner + "正在迁移…" / "正在创建…"）

**交互说明**：

| 元素 | 交互行为 | 触发条件 |
|------|---------|---------|
| 「更改」按钮 | 打开系统文件夹选择器 | 始终可点击 |
| 迁移选项卡片 | hover 边框高亮 → 点击执行迁移 | 弹窗打开后 |
| 创建空目录卡片 | hover 边框高亮 → 点击执行创建 | 弹窗打开后 |
| 取消按钮 | 关闭弹窗 | 弹窗打开后 |
| Modal 遮罩 | 点击关闭弹窗 | 弹窗打开后 |
| 执行中 | 弹窗内容切换为 loading，禁止关闭 | CLI 命令执行中 |

## 4. 状态枚举

### 4.1 页面级状态

| 状态 | 描述 | 视觉表现 |
|------|------|---------|
| 加载中 | 正在获取当前 config | 路径区显示骨架屏 |
| 正常 | 配置已加载 | 正常展示 |
| CLI 不可用 | CLI 未安装 | 源目录区「更改」按钮 disabled + 提示文案 |

### 4.2 迁移弹窗状态

| 状态 | 描述 | 视觉表现 |
|------|------|---------|
| 选择中 | 等待用户选择迁移方式 | 两个选项卡片可点击 |
| 执行中 | CLI 正在执行 | loading spinner + 文案 + 禁止关闭 |
| 成功 | 执行完成 | 弹窗自动关闭 + Toast 成功提示 |
| 失败 | 执行出错 | 弹窗内显示错误信息 + 重试/关闭按钮 |

### 4.3 主题选择器状态

| 状态 | 描述 | 视觉表现 |
|------|------|---------|
| 当前选中项 | 用户当前使用的主题 | 选中项背景高亮 + 阴影 |
| 其他选项 | 非当前主题 | 普通文字，hover 背景变化 |

### SettingsSection 规格

```
.settings-section
├── .settings-section__title     ← text-h3, --color-text-primary

└── .settings-section__content   ← 具体控件
```
- 使用 `.card` 作为容器基础
- 区块间距：`var(--space-5)`

```

├── .theme-selector__option--active     ← bg: --color-bg-default, shadow-xs, radius-sm
└── .theme-selector__label              ← text-body-sm
```

### PathDisplay 规格

```
.path-display                           ← flex, align-items: center, bg: --color-bg-subtle, radius-md, p: space-3 space-4
├── .path-display__icon                 ← 20px, --color-text-tertiary
```

## 8. 设计决策记录

| 编号 | 决策 | 备选方案 | 选择原因 |
|------|------|---------|---------|
| D-1 | 源目录展示为只读路径 + 更改按钮，而非可编辑输入框 | 输入框直接编辑 | 路径选择用系统选择器更准确，避免手动输入错误路径 |
| D-2 | 迁移确认用 Modal 弹窗而非页面内展开 | inline 展开区域 | 迁移是高风险操作，弹窗打断当前流程引起用户重视 |
| D-3 | 迁移选项用两个可点击 Card 而非 Radio + 确认按钮 | Radio 单选 + 确认 | 减少一步操作（点选即执行），选项少时 Card 更直观 |
| D-4 | 主题选择用 SegmentedControl | Select 下拉 | 三选项平铺一目了然 |
