# 需求文档：连接工具管理-新增与移除

> **任务编号**：FEAT-003
> **创建日期**：2026-04-30
> **状态**：已确认

---

## 1. 背景与目标

### 1.1 背景

当前「已连接工具」页面仅展示在 `aitools init` 时配置的 target 工具，只支持启用/禁用切换，不支持动态新增或移除工具。用户如果想添加一个新工具或删除不再使用的工具，必须手动编辑 `~/.aitools/config.yaml`。

### 1.2 目标

在已连接工具页面新增**添加工具**和**移除工具**功能，让用户可以在 GUI 中动态管理 target 列表。

|------|---------|--------|

| US-2 | 作为开发者，我希望移除一个不再使用的 AI 工具连接，以便保持列表整洁 | P0 |

## 3. 功能范围

### 3.1 包含（In Scope）

- [ ] **添加工具功能**
  - [ ] 页面顶部新增「添加工具」按钮
  - [ ] 点击后弹出工具选择弹窗，列出可添加的工具（排除已存在的）
  - [ ] 支持的工具清单（预定义）：
    - `codebuddy` — 用户级目录 `~/.codebuddy`，显示名 "CodeBuddy"
    - `workbuddy` — 用户级目录 `~/.workbuddy`，显示名 "WorkBuddy"
    - `claude-internal` — 用户级目录 `~/.claude-internal`，显示名 "Claude Internal"
  - [ ] 选择后调用 CLI 命令新增 target 到 config.yaml
  - [ ] 新增后自动启用该工具
  - [ ] 操作完成后刷新列表 + Toast 提示

- [ ] **移除工具功能**
  - [ ] 每个工具行右侧新增垃圾桶图标按钮（hover 时显示）
  - [ ] 点击后弹出确认弹窗：「确认移除 XXX？移除后该工具将不再接收资源同步，已同步的文件不会被删除。」
  - [ ] 确认后调用 CLI 命令 `aitools target remove <name>` 从 config.yaml 移除 target
  - [ ] 取消则关闭弹窗，无操作
  - [ ] 操作完成后刷新列表 + Toast 提示
  - [ ] 启用/禁用开关保留原有行为（`target enable/disable`），与移除互不干扰

- [ ] **CLI 新增命令**
  - [ ] `aitools target add <name>` — 新增 target（使用预定义 user_base，默认 enabled: true）
  - [ ] `aitools target remove <name>` — 移除 target（从 targets 数组删除）

### 3.2 不包含（Out of Scope）

- 自定义工具（用户自行输入名称和目录）——后续需求
- 工具的详细配置编辑（如修改 user_base 路径）
- 工具连接状态检测（检查目录是否实际存在）

## 4. 验收标准（Acceptance Criteria）

### US-1 验收标准

- [ ] **Given** 用户在已连接工具页 **When** 点击「添加工具」**Then** 弹出工具选择弹窗，列出可添加的工具（已存在的不显示）
- [ ] **Given** 弹窗中有可选工具 **When** 用户选择一个工具 **Then** 工具被添加到 config，列表刷新显示新工具（已启用状态）
- [ ] **Given** 所有工具都已添加 **When** 点击「添加工具」**Then** 弹窗提示「所有支持的工具已添加」

### US-2 验收标准

- [ ] **Given** 用户在工具列表中 **When** 点击某工具行右侧的垃圾桶按钮 **Then** 弹出确认弹窗
- [ ] **Given** 确认弹窗 **When** 用户点击「确认移除」**Then** 工具从 config 中移除，列表刷新，Toast 提示成功
- [ ] **Given** 确认弹窗 **When** 用户点击「取消」**Then** 弹窗关闭，无操作
- [ ] **Given** 移除成功 **When** 查看该工具目录 **Then** 已同步的文件保留不清理
- [ ] **Given** 用户切换开关 **When** 关闭/打开 **Then** 仅 disable/enable 该工具（不移除），行为与之前一致

- **数据结构**：target 在 config.yaml 中的结构为 `{ name, enabled, user_base }`
- **外部依赖**：无
